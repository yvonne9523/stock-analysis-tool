# 📈 股票基本面與技術面分析小工具 (Streamlit App)

這是一個基於 Python 與 Streamlit 打造的股票分析工具，提供基本面指標評估、技術面 K 線與訊號偵測，並能直接部署至 GitHub + Streamlit Community Cloud。

## 🚀 部署教學 (5分鐘完成)

1. 將此倉庫 (Repository) Fork 或 Clone 到你的 GitHub 帳號下。
2. 前往 [Streamlit Community Cloud](https://share.streamlit.io/) 並使用 GitHub 帳號登入。
3. 點選 **New app**。
4. 選擇本專案倉庫、分支 (`main` 或 `master`)，並將 Main file path 設定為 `app.py`。
5. 按下 **Deploy!** 即可完成部署並獲得專屬公開網址！

## 🛠️ 本地端測試方法

```bash
# 1. 安裝套件
pip install -r requirements.txt

# 2. 啟動 Streamlit
streamlit run app.py
```
